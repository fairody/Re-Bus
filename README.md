# Re:Bus (demo)

Локальный демо‑сайт проекта **Re:Bus** — единая платформа бесшовных поездок «река + автобус» (Москва).

## Что реализовано

- **Карта**:
  - отображаются **причалы** и **автобусные остановки**
  - показываются ближайшие отправления судов по расписанию (`RIVER_SCHEDULE` в data.js) и автобусные маршруты с оценкой интервала
- **Планировщик поездок**:
  - две точки **A** и **B** на карте (адреса через reverse geocoding)
  - мультимодальный маршрут: **пешком или на автобусе → речной маршрут → пешком или на автобусе**; для участков до и от причала можно выбрать пеший или автобусный вариант
  - автобусные участки идут по реальным линиям и остановкам OpenStreetMap
  - пересадки между линиями: по воде — на «Киевском» (маршруты 1 и 4) и на «ЗИЛе» (2 и 3); между этими двумя группами линий, которые по реке не связаны, — наземная пересадка (автобус или пешком, например «Лужники» → «ЗИЛ»)
  - причалы и пересадки выбираются поиском по сети линий с наименьшим общим временем; пешие минуты считаются вдвойне (лучше дольше плыть, чем долго идти), а пешие подходы к выбранным причалам проверяются по реальным пешеходным маршрутам
  - короткие поездки (до 20 минут пешком) предлагаются пешком, остальные — по реке

## Запуск на localhost

```bash
node server.js
```

Откройте в браузере `http://localhost:5174`

Статический сервер не подойдёт: поиск автобусных линий, пешеходная прокладка и reverse geocoding требуют прокси из server.js.

## Ограничения демо

- В демо включены линии **1-й речной: Киевский — Парк «Фили»**, **2-й речной: ЗИЛ — Печатники**, **3-й речной: Новоспасский — ЗИЛ** и **4-й речной: Лужники — Киевский**.
- Причалы «Воробьёвская набережная» и «Новодевичьи пруды» (маршрут 4) нанесены приблизительно: их открытие анонсировано на конец 2026 года, в OSM их пока нет.
- Речной транспорт — по опубликованному расписанию mos.ru: ежедневно 07:00–23:00, интервал 15–30 мин (в час пик 15–18). Расписания по отдельным линиям не опубликованы, поэтому у всех линий общий график.
- Автобусы: время поездки и интервалы — оценка (по типу маршрута); реальные расписания с transport.mos.ru пока не подключены.
- Данных в реальном времени (положение судов и автобусов) нет: они доступны только по соглашению с Дептрансом.
- Автобусные линии и остановки берутся из OpenStreetMap; полнота зависит от актуальности карты.
- Для автобусной части поддерживается одна пересадка между автобусами.
